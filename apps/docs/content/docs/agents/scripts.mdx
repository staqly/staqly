Use the REST API when your automation is a script, a backend service or anything else that
is not an MCP agent. Everything the dashboard and the agents do goes through this same API at
`http://localhost:3333`. In local mode, scripts on this machine need no credentials; in cloud
mode add `Authorization: Bearer stk_...`.

## Example: list pending items and decide them

This example lists pending images, then approves, rejects and regenerates items. Set `ITEM`
to an item ID (`itm_oalirbz67y4m4cqxq5dw`) first.

```bash tab="curl"
API=http://localhost:3333

# pending images across all collections
curl -s "$API/v1/items?status=pending&type=image"

# approve (optionally editing first) / reject with feedback / run a custom action
curl -s -X POST $API/v1/items/$ITEM/actions/approve    -H 'Content-Type: application/json' -d '{"edits":{"content":"Fixed caption"}}'
curl -s -X POST $API/v1/items/$ITEM/actions/reject     -H 'Content-Type: application/json' -d '{"feedback":"Too dark"}'
curl -s -X POST $API/v1/items/$ITEM/actions/regenerate -H 'Content-Type: application/json' -d '{"feedback":"Make her smile"}'

# history
curl -s $API/v1/items/$ITEM/events
```

```ts tab="TypeScript SDK"
import { Staqly } from '@staqly/sdk';

const staqly = new Staqly(); // local mode: http://localhost:3333, no key

for await (const item of staqly.items.iterate({ status: 'pending', type: 'image' })) {
  console.log(item.id, item.title);
}

await staqly.items.approve(itemId, { edits: { content: 'Fixed caption' } });
await staqly.items.reject(otherId, { feedback: 'Too dark' });
await staqly.items.action(thirdId, 'regenerate', { feedback: 'Make her smile' });
```

```python tab="Python SDK"
from staqly import Staqly

with Staqly() as staqly:  # local mode: http://localhost:3333, no key
    for item in staqly.items.iterate(status="pending", type="image"):
        print(item.id, item.title)

    staqly.items.approve(item_id, edits={"content": "Fixed caption"})
    staqly.items.reject(other_id, feedback="Too dark")
    staqly.items.action(third_id, "regenerate", feedback="Make her smile")
```

The SDKs install with `npm install @staqly/sdk` and `pip install staqly`; see the
[TypeScript SDK](/sdk/typescript) and [Python SDK](/sdk/python) pages.

To create items, see [Create your first item](/quickstart#create-your-first-item) in the
Quickstart.

## Calling staqly from inside Docker

A script running in a container uses the API's service name on the staqly network
(`http://api:3333`) or `http://host.docker.internal:3333`. Both are recognized as local
names. Any other host name must be added to `LOCAL_ALLOWED_HOSTS`, otherwise keyless requests
get `403 not_local`.

## Loading demo data

`scripts/seed.sh` in the repository (`make seed` from a checkout) loads three collections and a
handful of items through the public API, so events and webhooks fire as usual. It calls
`http://localhost:3333`, so it works with `staqly serve` and Docker alike. In
cloud mode:
`STAQLY_API_URL=https://staqly.example.com STAQLY_API_KEY=stk_... scripts/seed.sh`.
