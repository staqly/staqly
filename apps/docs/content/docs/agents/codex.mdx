Connect the Codex CLI to staqly as an MCP server, and Codex can create items, list what is
pending and act on your decisions, just from your prompts. You set it up once per machine.

## Connect to local staqly

<Steps>
<Step>

### Start staqly

Run `staqly serve` (or the [Docker image](/self-hosting/docker)). See the [Quickstart](/quickstart).

</Step>
<Step>

### Add the MCP server

In local mode, no key is needed:

```bash
codex mcp add staqly --url http://localhost:3333/mcp
```

Or merge this into `~/.codex/config.toml`:

```toml title="~/.codex/config.toml"
[mcp_servers.staqly]
url = "http://localhost:3333/mcp"
```

</Step>
</Steps>

Tip: `staqly mcp config codex` prints the command and the TOML for your current
[CLI](/cli/commands) profile.

### STDIO (Docker only)

With Docker you can use STDIO instead. It runs `mcp-stdio` inside the `staqly` container,
so it does not work with `staqly serve`:

```bash tab="Command"
codex mcp add staqly -- docker exec -i staqly mcp-stdio
```

```toml tab="config.toml" title="~/.codex/config.toml"
[mcp_servers.staqly]
command = "docker"
args = ["exec", "-i", "staqly", "mcp-stdio"]
```

## Connect to a cloud instance

Codex reads the bearer token from an environment variable:

```bash
export STAQLY_API_KEY=stk_...
codex mcp add staqly --url https://staqly.example.com/mcp --bearer-token-env-var STAQLY_API_KEY
```

```toml title="~/.codex/config.toml"
[mcp_servers.staqly]
url = "https://staqly.example.com/mcp"
bearer_token_env_var = "STAQLY_API_KEY"
```

STDIO against a cloud-mode container on the same host forwards the key into the container.
`codex mcp add --env` writes the key's value into `~/.codex/config.toml`
(`[mcp_servers.staqly.env]`), so keep that file private:

```bash
codex mcp add staqly --env STAQLY_API_KEY=$STAQLY_API_KEY -- docker exec -i -e STAQLY_API_KEY staqly mcp-stdio
```

`await_decision` waits 45 s per call by default, under Codex's 60 s tool timeout, and returns
`decided: false` when nobody has decided yet. To let one call wait longer (up to 300 s), raise
`tool_timeout_sec` in the server's `[mcp_servers.staqly]` block.

<Callout title="Verified">
With Codex CLI 0.162.1, `codex exec` called `staqly/create_item` (with a bearer key) and
`staqly/list_pending_approvals` (keyless) successfully.
</Callout>
