---
title: Claude Code
description: Add staqly to Claude Code over Streamable HTTP or STDIO.
---

## Local mode (no key)

```bash tab="HTTP (recommended)"
claude mcp add --transport http staqly http://localhost:3333/mcp
```

```bash tab="STDIO"
claude mcp add staqly -- docker exec -i staqly-api mcp-stdio
```

Check the connection:

```bash
claude mcp list        # → staqly: http://localhost:3333/mcp (HTTP) - ✔ Connected
```

### Project-scoped `.mcp.json`

Commit this to your repository so everyone working in it gets staqly:

```json title=".mcp.json"
{ "mcpServers": { "staqly": { "type": "http", "url": "http://localhost:3333/mcp" } } }
```

## Cloud instance

Create a key per agent under **Integrations → API keys** — e.g. a *Reviewer agent* key with
`collections:read items:read items:review` — and pass it as a header:

```bash
export STAQLY_API_KEY=stk_…
claude mcp add --transport http staqly https://staqly.example.com/mcp \
  --header "Authorization: Bearer $STAQLY_API_KEY"
```

Or in `.mcp.json` — Claude Code expands `${STAQLY_API_KEY}` from the environment, so the key
stays out of git:

```json title=".mcp.json"
{
  "mcpServers": {
    "staqly": {
      "type": "http",
      "url": "https://staqly.example.com/mcp",
      "headers": { "Authorization": "Bearer ${STAQLY_API_KEY}" }
    }
  }
}
```

STDIO against a cloud-mode container on the same host forwards the key into the container:

```bash
claude mcp add staqly -e STAQLY_API_KEY=stk_… -- docker exec -i -e STAQLY_API_KEY staqly-api mcp-stdio
```
