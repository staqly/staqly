The media editor opens pictures from **Media** in a full-screen editor. It runs in your browser (nothing is
uploaded while you edit) and is built on [OpenGPEX](https://github.com/gpex-cloud/opengpex), an open-source
image editor (GPL-3.0).

## Open it

- **Edit** in a picture's drawer opens that picture.
- Select several pictures and choose **Edit**: the first one opens as the picture, every other one becomes a
  layer on it, ready to combine.
- In a post, the pencil on an attached picture opens it in a new tab. Save it there and the post uses the edited
  picture; close the tab to go back.
- A saved project opens with its layers (see [Save](#save)).

The editor needs **WebGPU**: a current Chrome or Edge, or Safari 26 or later. Other browsers show a message and
your files stay as they are.

## Edit

The editor keeps the original pixels and stores your edits as steps, so **undo** and **redo** never lose
quality.

- **Layers**: order, show and hide, opacity and blend modes, lock, duplicate, delete, group.
- **Move and transform** layers, **crop**, resize the canvas, rotate and flip.
- **Text** with web fonts, **shapes** (rectangles, arrows, markers), **brush** and **eraser** (the eraser
  paints a mask, so erased parts come back).
- **Adjustments**: brightness, contrast, saturation, curves, levels, color balance, channel mixer.
- **Selections**: rectangle, ellipse, lasso, magic wand.

### On-device AI tools

The AI tools in the editor's right bar run in your browser. The first use of a tool downloads its model from
Hugging Face (tens to hundreds of MB, cached afterwards); your picture never leaves your computer.

| Tool | Model | License |
|---|---|---|
| Remove the background | InSPyReNet | MIT |
| Select an object | SAM 2.1 | Apache-2.0 |
| Erase an object (rebuild what was behind it) | LaMa | Apache-2.0 |
| Upscale 4x | Real-ESRGAN | BSD-3-Clause |

## Save

**Save as new file** (the default) exports the picture at full size into the library, next to the original,
in the original's format when it can hold the result (JPG stays JPG; anything with see-through areas is PNG).
The original never changes unless you choose so.

From the arrow beside it:

- **Replace the original**: the edited picture takes the original's place, with its name, alt text, folder and
  tags, and the **drafts** that use it use the edit. The original moves to **Deleted** (restorable for 30 days).
  If a scheduled, publishing or published post uses the original, the edit is refused and saved as a new file
  instead: posts that are on their way or out keep exactly what they had.
- **Save as a project**: keeps everything editable (layers, text, masks) to continue later. Projects count
  toward your storage.
- **Download** the picture.

Leaving with unsaved changes asks first. Opened from a post, **Back to the post** returns there with the saved
picture.

## AI with your own key

**AI** in the editor's bar makes a picture from a description (added as a layer), changes the picture by a
description (the result as a layer on top, so hiding or deleting it goes back), removes an area you paint over,
and extends the picture to a placement's shape (a new version). Each request shows its progress and can be
canceled or retried. Without a key these are off, with a **Set up AI** link for admins.

These tools use your workspace's own OpenAI account: an admin adds an API key under **Integrations › AI**. staqly checks the key with OpenAI (which costs nothing), stores it encrypted and never shows it
again (only its last four characters). OpenAI bills the calls to that key; staqly does not.

- A picture is sent to OpenAI only when someone clicks an AI action.
- The image model decides what is possible: `gpt-image-1` (the default) generates, edits by prompt, changes a
  marked area and extends a picture; `dall-e-3` only generates. Actions the model can't do are off, with the
  reason.
- At most 30 AI pictures per 10 minutes per workspace. Self-hosted servers can turn the AI tools off with
  `AI_DISABLED=true`.

The API: `GET`, `PUT` and `DELETE /v1/ai`, `POST /v1/ai/images/generate` and `/v1/ai/images/edit`. See the
[API reference](/api).
