This is the complete, endpoint-by-endpoint reference. Come here when you know what you want
to do and need the exact path, fields or response shape. New to the API? Start with the
[REST API overview](/api) and its four-step walkthrough.

## Find an endpoint

<Steps>
<Step>
### Pick the area

Endpoints are grouped by tag: posts, channels, schedules, webhooks and so on (see the cards below). Each area's
page lists its operations.
</Step>
<Step>
### Read the operation

Each operation has its own page with its parameters, request body, responses and generated code samples.
</Step>
<Step>
### Add authentication

Every request sends `Authorization: Bearer ...`: in **Staqly Community Edition** the access token staqly prints at
start (`staqly serve token`), in **cloud mode** an API key `stk_...`; the
scope each operation needs is listed in [Authentication & scopes](/api/authentication#scopes).
</Step>
</Steps>

## Where it comes from

These pages are generated at build time from
[`apps/api/openapi.yaml`](https://github.com/staqly/staqly/blob/main/apps/api/openapi.yaml) — the
same OpenAPI 3.2 contract the dashboard and the SDKs are typed from. A running
instance serves it at `http://localhost:3333/openapi.yaml`; this site has a copy at
[/openapi.yaml](/openapi.yaml). Load it into your own tools (code generators, HTTP clients) to
get the whole API at once.

## Try a request

Every endpoint has a **Send** button that calls **your cloud instance** straight from your
browser:

1. In the server field, pick `https://{host}` and enter your instance's host name.
2. Under authorization, paste an API key (`stk_...`) from **Integrations → API keys**. Use a key
   with only the scopes you want to try; it is kept in this browser.
3. Fill in the parameters and press **Send**.

This works because cloud mode allows browser calls with an API key from this site
(`CORS_ALLOWED_ORIGINS`, default `https://docs.staqly.ai`; see
[Configuration](/self-hosting/configuration)). It does not work against `localhost`: the Community Edition
never answers browser calls from other websites. For your Community Edition install, use
curl, the [CLI](/cli) or an [SDK](/sdk/typescript).
